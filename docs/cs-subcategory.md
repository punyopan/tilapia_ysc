# สาขาย่อยในสาขาวิทยาการคอมพิวเตอร์ / Which CS subcategory

สาขาวิทยาการคอมพิวเตอร์ของ YSC มี 7 สาขาย่อย การเลือกสาขาย่อยสำคัญพอ ๆ กับการเลือก
สาขาหลัก เพราะกำหนดว่าจะถูกเปรียบเทียบกับโครงงานแบบใด

## แนะนำ: CSBI — ชีววิทยาเชิงคำนวณและชีวสารสนเทศ

**Computational Biology and Bioinformatics**

นี่คือสาขาย่อยเดียวที่ทำให้เก็บงานทั้งหมดไว้ได้ โดยที่ทุกส่วนนับเป็นผลงาน ไม่ใช่
ส่วนประกอบ

| ส่วนของงาน | สถานะใน CSBI |
|---|---|
| การสกัดข้อมูลจากข้อความภาษาไทย | **literature mining** — วิธีมาตรฐานของชีวสารสนเทศมานาน |
| แบบจำลองเครือข่ายการแพร่กระจาย | **ระบาดวิทยาเชิงคำนวณ** — เป็นผลงานโดยตรง |
| แบบจำลองการกลับมาระบาดซ้ำ / ความคงทนของการกำจัด | **นิเวศวิทยาเชิงทฤษฎี** — ข้อค้นพบที่เป็นของใหม่ที่สุด |
| การวิเคราะห์กำลังการจำแนก | ระเบียบวิธีเชิงคำนวณ — เป็นสิ่งที่สาขานี้ให้คุณค่าสูง |

**เหตุผลสำคัญ:** การขุดข้อความจากวรรณกรรมเพื่อสร้างชุดข้อมูลทางชีววิทยา เป็นงาน
ชีวสารสนเทศที่ยอมรับกันมานาน (เช่น การขุดความสัมพันธ์ยีน–โรคจากบทความ) ดังนั้น
ระบบสกัดข้อมูลของเราไม่ได้ผิดที่ผิดทางเลย ส่วนแบบจำลองการแพร่กระจายและการกลับมา
ระบาดซ้ำคือชีววิทยาเชิงคำนวณโดยตรง

ที่สำคัญที่สุด: **ข้อค้นพบเรื่องความคงทนของการกำจัด** — ว่าการกำจัดจะถาวรหรือเป็น
เพียงการบำรุงรักษา ขึ้นกับแรงกดดันการรุกรานซ้ำ และหน้าต่างนี้ปิดลงเมื่อเครือข่าย
อิ่มตัวเกินราว 60% — เป็นผลงานชีววิทยาเชิงคำนวณที่เป็นของใหม่ ใน CSBI มันคือ
**ผลงานหลัก** ไม่ใช่ของแถม

## ทางเลือกสำรอง: CSSD — การออกแบบซอฟต์แวร์และวิทยาการข้อมูล

**Software Design and Data Science**

เหมาะถ้าอยากให้ตัวระบบและการประเมินเป็นผลงานหลัก (`benchmark.py` การเปรียบเทียบ
ห้าระบบ การ ablate อัตราการกุตำแหน่ง) เป็นกรอบที่แข็งแรงและวัดผลได้ชัด แต่ชีววิทยา
จะกลายเป็นเพียงโดเมนที่ใช้ประเมิน และข้อค้นพบเรื่องความคงทนจะถูกลดบทบาท

เลือก CSSD ถ้าชุดข้อมูลที่ติดป้ายด้วยมือเสร็จทันและมั่นใจในผลการเปรียบเทียบระบบ
เลือก CSBI ถ้าอยากให้ข้อค้นพบทางชีววิทยาเป็นตัวชูโรง

## ไม่แนะนำ: CSAI — ปัญญาประดิษฐ์และการเรียนรู้ของเครื่อง

**Artificial Intelligence and Machine Learning**

เป็นสาขาย่อยที่ดูน่าสนใจที่สุดและเป็นกับดักที่ชัดเจนที่สุด

โครงงานนี้**ไม่ได้ฝึกแบบจำลองใด ๆ** ไม่มีสถาปัตยกรรมใหม่ ไม่มีอัลกอริทึมการเรียนรู้
ใหม่ ไม่มีการปรับแต่งน้ำหนัก สิ่งที่ทำคือเรียกใช้แบบจำลองภาษาสำเร็จรูปผ่าน API
พร้อม prompt และ schema ที่ออกแบบมาดี ซึ่งเป็นวิศวกรรมที่ดี แต่ในสาขา CSAI จะถูก
เปรียบเทียบกับโครงงานที่ฝึกแบบจำลองจริง และคำถามแรกของกรรมการคือ
"ส่วนไหนคือการเรียนรู้ของเครื่อง"

หลีกเลี่ยง เว้นแต่จะเปลี่ยนโครงงานให้มีการฝึกแบบจำลองจริง ซึ่งไม่คุ้มกับเวลาที่เหลือ

## สาขาย่อยที่ไม่เกี่ยวข้อง

CSEB (ระบบสมองกลฝังตัว), CSRO (หุ่นยนต์), CSAR (ศิลปะและปฏิสัมพันธ์ดิจิทัล) —
ไม่ตรงกับงานนี้ ส่วน CSOT (อื่น ๆ) ไม่ควรใช้เมื่อมีสาขาย่อยที่ตรงอยู่แล้ว เพราะ
การเลือก "อื่น ๆ" ทั้งที่มีที่ลง มักถูกอ่านว่าไม่เข้าใจงานของตัวเอง

## สรุป

| สาขาย่อย | เหมาะ | ความเสี่ยง |
|---|---|---|
| **CSBI** | **แนะนำ** — เก็บงานได้ทั้งหมด ข้อค้นพบทางชีววิทยาเป็นผลงานหลัก | กรรมการอาจคาดหวังงานลำดับพันธุกรรม ต้องอธิบายว่าชีววิทยาเชิงคำนวณกว้างกว่านั้น |
| CSSD | สำรอง — ระบบและการประเมินเป็นผลงานหลัก | ชีววิทยาถูกลดเป็นโดเมน |
| CSAI | ไม่แนะนำ | ไม่มีการฝึกแบบจำลอง จะถูกถามทันที |
