# ถ้าจะส่ง CSAI — ปัญญาประดิษฐ์และการเรียนรู้ของเครื่อง

**Artificial Intelligence and Machine Learning**

ยังยืนยันว่า CSBI เหมาะกว่าถ้าใช้งานที่มีอยู่ตามเดิม แต่ถ้าจะส่ง CSAI จริง ๆ
นี่คือรูปแบบที่ผ่านได้ ไม่ใช่การเปลี่ยนคำอธิบาย แต่ต้องมี **การฝึกแบบจำลองจริง**

กรรมการ CSAI จะถามคำถามเดียวก่อนคำถามอื่นทั้งหมด: *"ส่วนไหนคือการเรียนรู้ของเครื่อง"*
ถ้าคำตอบคือ "เรียก API ของแบบจำลองภาษา" คือจบ — นั่นคือการใช้เครื่องมือ ไม่ใช่
การเรียนรู้ของเครื่อง

---

## คำถามวิจัย

> แบบจำลองภาษาไทยขนาดเล็กที่รันได้เอง ซึ่งฝึกจากคำอธิบายที่สร้างโดยแบบจำลองภาษา
> ขนาดใหญ่ จะทำงานสกัดและระบุตำแหน่งการพบชนิดพันธุ์ต่างถิ่นได้เทียบเท่าแบบจำลอง
> ขนาดใหญ่หรือไม่ ด้วยต้นทุนเพียงเศษเสี้ยวและไม่ต้องพึ่งพา API

เรียกว่า **knowledge distillation** ครูคือ pipeline ที่มีอยู่แล้ว นักเรียนคือ
แบบจำลองที่ต้องฝึกใหม่ และผลงานคือตัวนักเรียนกับคำตอบว่าแทนครูได้แค่ไหน

**ทำไมคำถามนี้ดี**

- เป็น ML แท้ — มีการฝึก มีชุด train/val/test มี learning curve
- มีเส้นฐานที่สะอาด: ตัวครูเอง
- มีแรงจูงใจจริง: ต้นทุน API, การใช้งานออฟไลน์, ข้อมูลไม่ต้องออกนอกองค์กร
- **ความล้มเหลวให้ข้อมูล** — คาดว่านักเรียนจะเทียบเท่าครูในกรณีง่าย และแพ้ในกรณี
  กำกวม ขนาดของช่องว่างนั้นคือผลลัพธ์
- ตอบโจทย์เรื่องต้นทุนที่เคยกังวลไว้ตั้งแต่ต้น โดยเปลี่ยนปัญหาให้เป็นงานวิจัย

## สถาปัตยกรรม

```
เอกสารไทย ──▶ ครู: LLM + schema ──▶ ป้ายเงิน (silver) ──▶ ฝึกนักเรียน
   ~5,000             (มีอยู่แล้ว)        ~5,000 ชิ้น         WangchanBERTa
                                                                   │
ชุดทอง (gold) 400 รายการ ────────── ประเมิน ───────────────────────┘
   ติดป้ายด้วยมือ                  ครูไม่เคยเห็น
```

**นักเรียน:** ตัวเข้ารหัสภาษาไทยขนาดเล็ก — WangchanBERTa เป็นตัวเลือกมาตรฐานสำหรับ
ภาษาไทย หรือ XLM-R base ถ้าต้องการเทียบข้ามภาษา ฝึกสองงาน:

1. **Token classification** — ตัดสินว่าอักขระใดเป็นส่วนของชื่อสถานที่ (BIO ระดับ
   อักขระ เพราะภาษาไทยไม่เว้นวรรค และตัวตัดคำจะใส่ error ของตัวเองเข้ามา ซึ่งจะถูก
   นับเป็นความผิดของแบบจำลอง)
2. **Learning to rank** — เลือกว่าผู้สมัครรายการใดในฐานข้อมูลคือคำตอบ ส่วนนี้คือที่
   ที่ ML น่าสนใจที่สุด เพราะการรู้ว่า ต.บางแก้ว เป็นสถานที่นั้นง่าย แต่การรู้ว่า
   **บางแก้วไหน** ต้องรวมความคล้ายของสตริง ความสอดคล้องเชิงลำดับชั้น และความถี่
   ก่อนหน้าเข้าด้วยกัน

`distill.py` สร้างชุดข้อมูลทั้งสองแบบจากผลของ pipeline ที่มีอยู่แล้ว

## กฎเหล็กสองข้อ

**๑. ห้ามประเมินบนป้ายเงิน** นักเรียนที่ถูกประเมินด้วยผลของครู วัดได้แค่ความ
สอดคล้องกับครู ไม่ใช่ความถูกต้อง ถ้าครูผิดอย่างเป็นระบบ นักเรียนจะรับความผิดนั้นมา
และการประเมินจะมองไม่เห็น **ประเมินบนชุดทองที่ติดป้ายเองเท่านั้น**

**๒. ระวัง self-distillation ของกฎ** ถ้า gold index ในชุด linking มาจากตัวจับคู่
เชิงกฎ นักเรียนดีที่สุดก็แค่ทำซ้ำกฎได้ ดังนั้นข้ออ้างที่ซื่อสัตย์คือ *"แบบจำลองที่
เรียนรู้สามารถกู้คืนกฎที่เขียนด้วยมือจากข้อมูลได้หรือไม่"* ซึ่งน่าสนใจ แต่เป็นคนละ
ข้ออ้างกับ *"แบบจำลองที่เรียนรู้ดีกว่ากฎ"* ถ้าจะอ้างอย่างหลัง ต้องติดป้ายชุด linking
ด้วยมือ แล้วเทียบทั้งสองกับความจริง — แล้วฝ่ายใดชนะก็ได้

`distill.py` เขียนข้อจำกัดนี้ไว้ใน docstring แล้ว อย่าลืมพูดถึงในรายงาน

## ผลลัพธ์ที่ต้องรายงาน

| ตัวชี้วัด | ทำไมสำคัญ |
|---|---|
| F1 ของ NER (นักเรียน vs ครู) บนชุดทอง | ความสามารถหลัก |
| ความแม่นยำการระบุตำแหน่ง แยกตามประเภทความกำกวม | ที่ที่นักเรียนแพ้ |
| **Learning curve** — แม่นยำเทียบกับจำนวนตัวอย่างฝึก | รูปเดียวที่ให้ข้อมูลมากที่สุด |
| ต้นทุนต่อ 1,000 เอกสาร (นักเรียน vs ครู) | เหตุผลที่ทำทั้งหมดนี้ |
| ขนาดแบบจำลองและเวลาประมวลผล | รันได้จริงบนเครื่องธรรมดาหรือไม่ |

**Learning curve คือรูปที่ต้องมี** ฝึกนักเรียนที่ขนาดชุดฝึก 250 / 500 / 1000 /
2000 / 4000 แล้ววาดกราฟ มันตอบพร้อมกันว่า ต้องใช้คำอธิบายจากครูเท่าไรจึงพอ
ประสิทธิภาพอิ่มตัวหรือยัง และการจ่ายเงินให้ครูเพิ่มจะช่วยหรือไม่ `learning_curve_splits()`
สร้าง subset แบบซ้อนกันให้แล้ว (ซ้อนกัน เพื่อให้กราฟสะท้อนข้อมูลที่เพิ่มขึ้น ไม่ใช่
การสุ่มใหม่ในแต่ละจุด)

## ทรัพยากรและความเสี่ยง

**ทรัพยากร:** การ fine-tune BERT ขนาด base บนตัวอย่างไม่กี่พันชิ้น ใช้ Colab T4
ฟรีไม่ถึงหนึ่งชั่วโมง — นี่คือจุดเดียวในโครงงานทั้งหมดที่ใช้ GPU จริง และยังไม่
ต้องใช้ HPC

**ความเสี่ยงที่ต้องยอมรับ:**

1. **งานเพิ่มขึ้นมาก** เทียบกับ CSBI ซึ่งใช้ของที่มีอยู่แล้วได้เลย
2. ยังต้องมีชุดทอง 400 รายการเหมือนเดิม — ข้อกำหนดนี้ไม่หายไป
3. ต้องสร้างป้ายเงินก่อน ซึ่งใช้งบ API ที่ประเมินไว้ (~$18)
4. การ fine-tune ครั้งแรกมีเส้นโค้งการเรียนรู้ของตัวเอง เผื่อเวลาสำหรับการดีบัก
   ที่ไม่เกี่ยวกับวิทยาศาสตร์
5. **ผลลัพธ์ที่เป็นไปได้มากคือ นักเรียนแพ้ครูอย่างชัดเจนในกรณีกำกวม** ซึ่งไม่เป็นไร
   ถ้ารายงานเป็นผลการทดลอง แต่ต้องเตรียมใจว่าเรื่องเล่าจะไม่ใช่ "แบบจำลองเล็ก
   ชนะแบบจำลองใหญ่"

## ตัดสินใจอย่างไร

- **เวลาเหลือน้อย** → CSBI ใช้ของที่มีอยู่ ไม่ต้องฝึกอะไรใหม่
- **เวลาเหลือพอ และอยากอยู่ CSAI** → เส้นทางนี้ เป็นโครงงานที่ดีและเป็น ML จริง
- **อยากได้ทั้งสองอย่าง** → เป็นไปไม่ได้ในเวลาที่มี เลือกอย่างเดียว
